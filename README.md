# DBS Operations Intelligence Agent

An AI-powered operations analytics agent designed for enterprise shared-services use cases.

The project combines **MCP, PostgreSQL, Python, SQL, and machine learning** to analyze operational and financial data, detect anomalies, investigate performance variances, and identify potential root causes.

### Key capabilities
- Natural-language analytics over business data
- Automated SQL analysis
- Spend and budget variance investigation
- Invoice and operational anomaly detection
- Supplier performance analysis
- Root-cause analysis
- AI-generated management reports

> Portfolio project inspired by real-world enterprise operations and shared-services analytics scenarios.
